### 🚀 Projets - La Plateforme
#### 3ème année - Licence Administrateur d'Infrastructures Sécurisées
**Cybersécurité & Conformité**
- [**Plateforme SOC**](https://github.com/leon-camuzat/Plateforme_SOC) : mise en place d'une chaîne complète de supervision et de réponse à incident, du monitoring temps réel (Zabbix, Prometheus, Grafana) à l'analyse (Wireshark, ELK) et au traitement des incidents (TheHive, MISP). Détection d'activités anormales, alerting automatisé, réponse aux incidents documentée et audit de sécurité de l'infrastructure (Lynis, Docker Bench, Trivy).
- [**Projet RGPD**](https://github.com/leon-camuzat/Projet---RGPD) : audit de conformité RGPD d'une entreprise fictive (éditeur de logiciels) : registre des traitements, analyse d'impact relative à la protection des données (AIPD/DPIA), gestion et simulation de violation de données, audit de conformité global.
- [**Nessus : Découverte & Exploitation de Vulnérabilités**](https://github.com/leon-camuzat/Nessus) : chaîne complète de gestion de vulnérabilités en lab isolé (Nessus, Metasploitable 2, Kali) : scan et analyse par sévérité CVSS, exploitation via Metasploit (faille Samba « usermap_script » → accès root, session Meterpreter, post-exploitation) et remédiation. Durcissement préalable de l'infrastructure d'administration (compte sudo, SSH par clé ed25519, hardening sshd).

#### 2ème année - Licence Administrateur d'Infrastructures Sécurisées
**DevOps & Automatisation**
- [**GitHub Actions**](https://github.com/leon-camuzat/Github-Actions) : pipeline CI/CD sécurisé : vérification automatique du code à chaque push, gestion des secrets chiffrés, utilisateur de déploiement à moindre privilège avec clé SSH dédiée, et déploiement automatisé via Ansible sur une VM Debian.
- [**Terraform**](https://github.com/leon-camuzat/Terraform) : automatisation du déploiement d'une VM Debian 13 sur VMware Workstation et d'un lab cyber (VM attaquante + VM serveur Web), scan des ports d'écoute avec nmap.
- [**Ansible**](https://github.com/leon-camuzat/Ansible) : automatisation sans agent de la configuration et du hardening de 3 serveurs Linux : durcissement SSH, pare-feu UFW et gestion des services via playbooks.
- [**Kubernetes**](https://github.com/leon-camuzat/Kubernetes) : cluster K3S sur 3 VMs Debian (1 master, 2 workers), déploiement d'applications conteneurisées via YAML (Nginx, Apache, MariaDB), haute disponibilité avec replicas, stockage persistant, ConfigMaps, Secrets, RBAC et gestion via Helm.
- [**Docker Swarm**](https://github.com/leon-camuzat/Docker_Swarm) : cluster Docker Swarm de 7 VMs Debian (3 managers Raft, 3 workers, 1 serveur NFS) pour la continuité d'activité : services conteneurisés (Registry, MariaDB, PHP, Nginx, VSCode Server), supervision via Portainer, Prometheus et Grafana, validation par 3 tests PCA/PRA.
- [**Docker**](https://github.com/leon-camuzat/Docker) : prise en main de Docker sur VM Debian : installation, commandes de base, création d'images personnalisées via Dockerfile.

**Systèmes**
- [**Security Log Monitor**](https://github.com/leon-camuzat/PSMM) : scripts Python via SSH pour monitorer 3 serveurs Debian (FTP, Web, MariaDB) : collecte des tentatives d'accès échouées, stockage en base MariaDB et envoi de rapports automatiques par mail.
- [**Holodeck**](https://github.com/leon-camuzat/Holodeck) : serveur web multi-services sur VM Debian : Nginx HTTPS, PHP, MariaDB, FTP SSL/TLS, DHCP/DNS, annuaire LDAP pour l'authentification et pare-feu configuré.

**Cloud**
- [**Azure AD**](https://github.com/leon-camuzat/Azure_AD) : configuration et sécurisation de Microsoft Entra ID : politiques MFA et accès conditionnel, automatisation de la gestion des utilisateurs.
- [**AWS**](https://github.com/leon-camuzat/AWS_-_Azure) : administration d'une infrastructure AWS : gestion IAM (utilisateurs, groupes, moindre privilège, MFA), instances EC2 (Elastic IP, ENI, groupes de placement, hibernation), base RDS MySQL avec Read Replica et stockage S3.
